文炼工坊 TextForge —— 便携版
================================

运行方式
--------
双击 textforge.exe 即可，**不需要安装、不需要管理员权限、不写注册表**。

整个文件夹就是程序本体，可以随便放哪（D 盘、U 盘、网盘同步目录都行），
想换位置直接整个文件夹拖过去，不用卸载、不用重装。
删掉文件夹 = 彻底卸载，不会留任何东西在系统里。


里面有什么
----------
  textforge.exe    程序本体（双击这个）
  backend.exe      随附的本地服务，不用单独运行
  _internal\       backend.exe 依赖的运行库，**不要删、不要单独移动**
  data\            首次运行后自动生成，属于你自己

data\ 里是你的数据（章节历史、运行日志、端口记录）：
  data\logs\backend.log    排查问题时可看这个日志
  data\port.json           内部端口记录，不要手动改
  data\runs.json           任务历史，会在「任务历史」界面里出现

**小说成品不在这里** —— 成品路径是你在界面里自己选的，
通常是你填的输出目录下的 03_final 文件夹。

关于「删除文件夹是否等于没装过」
--------------------------------
实测：注册表、AppData、LocalAppData 均无新增项；
历史、日志、端口文件全部落在本文件夹内的 data\ 下。
整个文件夹删掉即彻底卸载，不会在系统里留下任何东西。


注意事项
--------
1. 需要 Windows 10 1809 及以上 / Windows 11。
   极少数未装 WebView2 的老系统需要先去微软官网装一次「WebView2 运行时」。
2. 本程序不会上传你的任何文件；所有处理都在你本机完成。
   但如果你选择连接本地大模型（LM Studio / Ollama 等），
   小说正文会发到你自己的那个模型服务上。
3. 杀毒软件误报：本程序未购买商业代码签名证书。
   若 Defender 仍误报，可在 Windows 安全中心 → 病毒和威胁防护 →
   保护历史记录 → 恢复被隔离的文件，并把本文件夹加入「排除项」。

启动前置条件
------------
若双击后窗口一闪即退，多半是没满足下列条件之一：
  - 杀毒软件拦截了 backend.exe（见上方注意事项 3）
  - 整个文件夹放在了受保护目录（如 C:\Program Files）里
  - 文件夹被压缩软件打包后直接双击运行（请先完整解压）
  - 手工整理过文件夹，把 _internal\ 挪走或删了（backend.exe 找不到依赖）
